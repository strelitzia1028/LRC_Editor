LRC 歌词编辑器 v5.6 Win7 支持版
================================

系统要求
--------
- Windows 7 SP1 64 位。
- 建议 4 GB 以上内存，200 MB 以上可用磁盘空间。
- 建议安装 Windows 7 的 SHA-2 代码签名支持更新（KB4474419）和服务堆栈更新（KB4490628）。
- 不需要另外安装 Java。

启动
----
双击“LRC Editor Win7.exe”即可运行。请保持整个文件夹结构不变，不要只复制 exe 文件。

本版本包含
----------
- Java 8 与 JavaFX 8 私有运行时。
- FFmpeg 4.4.1，用于将滚动歌词导出为 H.264 MP4 和 AAC 音轨。
- jFLAC，用于读取 FLAC 音频。
- 与桌面版 v5.6 相同的歌词编辑、深色/浅色外观、专辑封面和视频导出功能。

视频导出
--------
视频导出使用程序目录中的 app\ffmpeg\ffmpeg.exe。首次导出前不必配置路径。
取消或失败时会自动删除未完成的临时视频。

常见问题
--------
1. 双击后没有窗口
   先确认系统是 Windows 7 SP1 64 位，并安装上面的 SHA-2 更新。

2. 提示缺少 DLL
   请解压完整压缩包后再运行，保留 runtime、app 和根目录中的 DLL 文件。

3. 无法播放音频
   优先使用 MP3、WAV 或 FLAC。若仍无声，请检查系统默认播放设备和音频驱动。

4. 视频导出失败
   确认 app\ffmpeg\ffmpeg.exe 存在，并检查目标目录是否有写入权限。

数据与设置
----------
界面主题、上次打开目录等设置保存在当前 Windows 用户的 Java 偏好设置中。
歌词、音频和导出的视频仍保存在用户选择的位置。

重要说明
--------
本版本以 Windows 7 SP1 x64 为兼容目标构建。正式分发前，建议在一台实际的
Windows 7 SP1 电脑上完成启动、音频播放和视频导出的最终验收。
