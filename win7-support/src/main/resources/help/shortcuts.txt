================================================================
  快捷键速查
================================================================

【文件】
  Ctrl + O            导入歌词（.lrc / .txt）
  Ctrl + Shift + O    导入音频（.mp3 / .wav / .flac）
  Ctrl + S            保存
  Ctrl + Shift + S    另存为

【编辑】
  Ctrl + Z            撤销
  Ctrl + Y            重做
  Ctrl + A            全选所有非空行
  Ctrl + T            用当前播放时间覆盖选中行
  Ctrl + Shift + T    批量偏移选中时间戳
  Ctrl + N            在选中行下方插入新行
  Ctrl + D            删除选中行

【列表焦点】
  Space               批量打时间戳（等价 Ctrl+T）
  Delete              删除选中行
  Insert              插入新行
  Enter               从选中行开始播放

【编辑状态】
  Enter               提交并退出当前行编辑

【多选】
  Shift + 单击        连续范围选择
  Ctrl  + 单击        独立加减选择
  Ctrl + A            全选

【播放】
  单击左侧播放按钮     播放 / 暂停
  单击波形图           跳转到对应时间播放
  单击绿色 ▶           跳转到该组时间戳

【视频设置窗口】
  拖动时间轴           定位预览，可反复播放
  单击小喇叭           仅静音/开启预览声音
  单击播放按钮         暂停或继续预览
  “截取片段”           默认关闭，开启后可用绿/红箭头截取
