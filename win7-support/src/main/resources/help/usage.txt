================================================================
  LRC 歌词编辑器 v5.6 · 使用说明
  by 忆昔风依旧
================================================================

本说明适用于 v5.6 桌面版。建议首次使用时按“快速开始”完成一遍，
再根据需要查看歌词编辑、视频生成和排错部分。

一、快速开始
----------------------------------------------------------------
  1. 导入音频：按 Ctrl+Shift+O，选择 MP3、WAV 或 FLAC。
  2. 导入歌词：按 Ctrl+O；也可以新建文档后直接输入歌词。
  3. 在歌词列表中单击选中一行，播放到目标位置后按 Space 打时间戳。
  4. 按 Ctrl+S 保存歌词。
  5. 需要视频时，打开“视频 → 一键生成视频”，调整设置后点击开始生成。

二、主界面与歌词编辑
----------------------------------------------------------------
  · 左侧是编辑和同步选项，中部是歌词列表，顶部显示滚动歌词预览，
    底部是播放控制和波形图。
  · 第一次单击一行：只选中该行。
  · 再次单击已选中的行：进入文字或时间戳编辑。
  · 编辑状态按 Enter：提交修改并退出编辑。
  · 列表有焦点时按 Enter：从当前选中行开始播放。
  · Shift+单击：连续选择多行。
  · Ctrl+单击：逐行增加或取消选择。
  · Ctrl+A：选择全部非空歌词行。
  · Ctrl+Z：撤销；Ctrl+Y：重做。批量操作会作为一步撤销。
  · Delete：删除选中行；Insert：在选中行后插入新行。
  · “歌词内容上移一格 / 下移一格”：只移动选中行的歌词文字，
    时间戳位置不变，可用 Ctrl+Z 一次撤销。
    第一行上移时新增时间戳为 0 的行存放原第一行内容；
    最后一行下移时新增比末尾时间戳晚 1 秒的行存放原最后一行内容。
  · 上移/下移下方的“转移/交换/覆盖”模式按钮，也可在
    “编辑 → 内容移动模式”中选择：
    转移模式为默认值：从选中行开始，沿移动方向的相邻行会依次被顶到
    上方或下方，并在原位置留下时间戳为 0 的空行。
    上移会在顶部补 0 ms 行，下移会在底部补末尾时间戳 +1 秒行。
    如果目标位置原本就是空歌词行，则直接移入空行，等同于覆盖，
    不会额外新增 0 ms 行。
    交换模式会推挤重叠行，把目标行内容移到腾空位置，避免丢失。
    覆盖模式会直接用选中内容覆盖目标行，原位置保留原时间戳。
    模式选择会自动保存。

三、自动选择、播放高亮与同步
----------------------------------------------------------------
  · 黄色高亮：当前播放位置对应的全部歌词行。同一时间戳的多行会一起高亮。
  · 蓝色高亮：用户手动选中的行；蓝色和黄色重合时显示为组合高亮。
  · “自动同步”：播放进入新的歌词组时，把蓝色选择同步到当前播放组一次。
    同步完成后仍可单击其他行进行选择或编辑，不会每帧强制抢回选择。
  · “自动选择同组”：单击一行时，同时选择所有相同时间戳的歌词行。
  · “自动扩选 N 行”：在单击选中的行之后，再向下选择 N 行。
    N 可填写 0 到 10；0 表示关闭，到达文件末尾时会自动截停。
  · “自动选择同组”和“自动扩选”不能同时开启。切换时会弹出确认提示，
    确认后才会关闭另一个功能。
  · “自定义提前 N ms”：仅提前歌词显示和播放高亮的判断位置，
    不会修改 LRC 文件中的实际时间戳。N 必须大于或等于 0。

四、批量编辑与时间戳
----------------------------------------------------------------
  · Ctrl+T 或列表焦点下按 Space：用当前播放时间覆盖选中行时间戳。
  · “自定义插入 N 行”：一次在当前位置后插入多个空歌词行。
  · “粘贴多行歌词”：按换行拆分剪贴板内容，并自动识别行内时间戳。
  · 粘贴时若某句没有时间戳，会继承上一句时间戳；
    若整段都没有时间戳，则全部初始化为 0。
  · “时间分块 / 统合”：按时间戳分组显示，便于查看同时间戳的多语言歌词。
    分块产生的空行只用于视觉间距，不参与选择和导出。
  · “修改 offset”：输入目标偏移量并整体移动时间戳；输入 0 恢复原始时间。

五、播放、波形与定位
----------------------------------------------------------------
  · 左侧播放按钮：播放或暂停。
  · 单击波形图：跳转到对应时间。
  · 单击歌词时间戳旁的绿色播放标记：跳到该时间戳组。
  · 播放到文件末尾后，波形会以平滑动画回到开头。
  · 导入较大的 FLAC 时，波形分析可能持续一段时间；
    进度会显示在界面中，请等待完成后再进行精细定位。

六、顶部歌词预览与外观
----------------------------------------------------------------
  · 顶部预览显示上一句、当前句和下一句，并与播放位置同步滚动。
  · 当前播放行使用更大字号和“当前播放行颜色”。
  · 在“视图 → 当前播放行颜色”中可选择黑、白、红、绿、蓝。
  · 切换浅色/深色模式时，当前播放行颜色会统一为黑色/白色；
    切换后仍可在视图中手动改色。
  · 默认使用深色模式。“外观”菜单可在浅色模式和深色模式间切换，
    选择会自动保存到下次启动。
  · 主题会应用到主界面、歌词列表、波形、菜单和视频设置窗口。
  · “视图”中还可调整输入框边框、手动选中高亮和播放高亮的可见度。
  · 封面可切换圆形黑胶或方形样式；圆形封面可单独设置高光和旋转速度。

七、文件导入、保存与歌词导出
----------------------------------------------------------------
  · 支持导入 .lrc 和 .txt；音频支持 MP3、WAV、FLAC 等常见格式。
  · 导入时自动识别 UTF-8、GBK 和 BOM。
  · Ctrl+S 保存，Ctrl+Shift+S 另存为。
  · “导出歌词”会打开独立导出窗口，可修改“保存路径”；
    未指定其他位置时默认使用桌面。
  · 导出窗口右侧是只读预览，可选中和复制文字。
  · “合并/分离相同内容的时间戳”会把内容相同但时间戳不同的歌词
    合并到首次出现的位置，并按时间从小到大排列多个时间戳。
  · 导出预览支持 Ctrl+滚轮缩放字号；预览下方会显示当前字号，
    点击旁边的“重置”可恢复默认字号。
  · “导出时写入 UTF-8 BOM”用于兼容部分老播放器。
  · 软件会记住上次打开或保存的文件夹，并在下次文件对话框中复用。

八、一键生成滚动歌词视频
----------------------------------------------------------------
  入口：顶部“视频 → 一键生成视频”。
  · 打开窗口时会自动暂停主界面播放，避免预览声音与导出任务互相干扰。
  · 必须至少有一行带时间戳的非空歌词，否则不会进入导出流程。
  · 视频默认歌词颜色为白色，可在画面设置中修改。

  1. 歌词动效
  · 直接显现模式
    - 直接显示：歌词到点出现、到点消失，没有渐变，也不会持续闪烁。
    - 单句渐显渐隐：当前句平滑出现，再平滑消失。
  · 正常滚动模式
    - 上下滚动：歌词整体由下向上快速切换，当前句位于可见区域中部。
    - 同屏行数可填写 1 到 10，默认 3 行。
    - 当前行字号大于非当前行；“非当前行缩小”可留空自动，
      也可填写 0 到“当前字号-1”的像素值。
    - 字号和行距可留空自动适配，也可手动填写。
    - 滚动速度可留空自动；填写 1.0 为标准，2.0 为两倍速，0.5 为半速。

  2. 背景与质感
  · 内置静态背景：深海蓝、暗夜、暖阳、纯黑。
  · 内置动态背景：缓慢缩放、蓝色呼吸、粒子漂浮。
  · 专辑封面：使用主界面当前封面。
    - 填充：保持比例并裁剪到铺满画面。
    - 合适：保持比例完整显示，允许留边。
    - 默认：保持比例，居中放大到刚好填满画面。
  · 自定义图片支持 jpg、jpeg、png；自定义视频支持 mp4、mkv。
  · 质感是叠加在背景上的统一效果：
    - 无效果：直接使用原背景。
    - 暗色+玻璃磨砂：可同时调整模糊程度、静态锐度颗粒和暗色程度。
    - 锐度颗粒是静态质感，不是逐帧变化的噪点。
    - 独立“恢复默认”会恢复模糊 35%、锐度颗粒 12%、暗色 35%。

  3. 画面与预览
  · 分辨率支持 1920×1080、1280×720、1080×1920、720×1280；
    预览会自动切换横屏或竖屏。
  · 帧率支持 30 FPS 和 60 FPS。
  · 左侧播放按钮控制预览播放/暂停。
  · 时间轴可拖动定位，可反复播放；下方提示会显示当前时间。
  · 右下角小喇叭只控制预览声音，不会把导出视频静音。
  · “截取片段”默认关闭。开启后，绿色箭头为开始，红色箭头为结束。
  · 拖动开始或结束箭头时会临时暂停并静音，松开后恢复原来的播放状态。
  · 播放到红色结束标记时停止；再次点击播放会从绿色开始标记重新播放。

  4. 生成与取消
  · 点击“开始生成视频”才会正式导出，按 Enter 不会误触发生成。
  · 生成期间请不要关闭程序或同时执行大型磁盘任务。
  · 点击取消后，未完成的视频会被自动删除，并显示“--已取消--”。
  · 正式视频只会在导出成功后写入目标位置。
  · 视频格式为 H.264 MP4，有音频时使用 AAC 音轨。

九、视频输出路径
----------------------------------------------------------------
  未手动选择输出文件时，路径优先级为：
    用户自定义路径 > 歌曲所在目录 > 歌词所在目录
  · 已导入歌曲：默认保存到歌曲目录。
  · 未导入歌曲但已导入歌词：默认保存到歌词目录。
  · 三者都不可用时：保存到当前用户目录。
  · 点击输出路径右侧的“选择…”可以随时覆盖默认路径。

十、恢复默认
----------------------------------------------------------------
  · 视频窗口底部提供“恢复默认设置”。
  · 质感区域提供独立的“恢复默认”。
  · 恢复默认会重置背景、质感、分辨率、帧率、歌词颜色、字号、行距、
    同屏行数（3 行）、滚动速度、非当前行缩小量和截取范围。
  · 恢复默认不会删除歌词、音频、已选择的自定义背景或已导出的文件。
  · 开始一次新的视频导出前，建议确认输出路径和颜色设置。

十一、常见问题
----------------------------------------------------------------
  · 打点后歌词没有高亮：确认该行有时间戳，并检查“自定义提前 N ms”。
  · 无法选中其他行：查看“自动同步”是否刚跳到新歌词组；
    同步只发生一次，随后可以正常手动选择。
  · 自动选择冲突：关闭“自动选择同组”或把“自动扩选”设为 0。
  · 导出的视频没有声音：确认已导入音频，且音轨能被播放器正常读取。
  · 视频预览没有声音：点击预览右下角的小喇叭解除静音。
  · 视频生成失败：确认目标目录可写，并检查软件目录中的 FFmpeg 是否完整。
  · 视频中途取消：检查目标目录中不会保留未完成的 MP4。
  · 设置没有保留：外观、颜色、提前量和上次目录会自动保存；
    其他视频参数在每次打开视频窗口时按当前设置重新确认。
